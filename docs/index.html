Which medicinal plants of South Asia are we losing, and which have never even been assessed?

RedRoot joins five open datasets with a model validated on plant families it never saw, to show which of 1,319 medicinal plants most urgently need an IUCN Red List assessment.

Findings

Two things the data revealed

Finding 1 · data quality

Synonyms hide threatened plants

GBIF attaches IUCN categories to the name IUCN used. When GBIF calls that name a synonym, the plant shows up as “Not Evaluated”. Kuth is Critically Endangered as Aucklandia costus, but GBIF’s accepted Dolomiaea costus returns nothing.

Status is transferred only from homotypic synonyms. A naive rule would make ashwagandha Critically Endangered via Withania chevalieri, a Cape Verde endemic. That candidate and 21 others are rejected and logged.

Finding 2 · the blind spot

Range-based screening misses the plants we harvest most
